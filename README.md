# ☁️ Небесная Лудка — Telegram Mini App

Бесплатная социальная игра-лудка в небесной стилистике: краш, мины, кейсы с настоящими названиями Telegram-подарков, апгрейдер, ежедневный бонус и таблица лидеров.

**Важно:** игра ведётся в виртуальных монетах без реальной стоимости. Реальные платежи не принимаются, выигрыши не выводятся. 18+.

## Структура

```
sky-ludka/
├── index.html      # единственная страница приложения
├── style.css       # небесный дизайн: облака, стекло, золото
├── script.js       # вся игровая логика
├── mascot.png      # маскот
├── terms.html      # пользовательское соглашение
├── privacy.html    # политика конфиденциальности
├── vercel.json
└── README.md
```

## Запуск локально

```bash
npx serve .        # или любой статический сервер
```

## Деплой на Vercel

1. Залей папку в новый GitHub-репозиторий (или загрузи файлы через веб-интерфейс GitHub).
2. На vercel.com нажми **Add New → Project** и импортируй репозиторий.
3. Framework Preset: **Other** (статический сайт). Жми Deploy.
4. Скопируй адрес вида `https://sky-ludka.vercel.app`.

## Подключение к Telegram

1. Открой [@BotFather](https://t.me/BotFather) → `/newbot` (или выбери существующего).
2. `/newapp` → выбери бота → загрузи картинку → укажи URL деплоя Vercel.
3. Готово: мини-приложение открывается по кнопке бота.
